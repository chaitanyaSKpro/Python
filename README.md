# 🎮 Rock Paper Scissors Game

This is a simple **Rock Paper Scissors** game made using Python 🐍.

I created this project to practice the Python concepts I have learned so far, like:
- Variables
- Input and Output
- Conditional Statements
- Loops
- Strings
- Basic Operators

## 🕹️ How the Game Works

- First, you enter how many rounds you want to play.
- In every round, **User 1** and **User 2** enter their choices.
- The game checks both choices and decides the winner.
- The score is updated after every round.
- At the end, the final scores are displayed and the overall winner is announced 🏆.

## ✊ Game Choices

You can choose:

- 🪨 Rock
- 📄 Paper
- ✂️ Scissor

### Rules

- 🪨 Rock beats ✂️ Scissor
- ✂️ Scissor beats 📄 Paper
- 📄 Paper beats 🪨 Rock
- Same choice = 🤝 Tie
